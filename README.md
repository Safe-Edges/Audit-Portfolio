## Audit Methodology

Our audit process is structured, repeatable, and aligned with industry best practices:

| Phase                    | Description                                             |
| ------------------------ | ------------------------------------------------------- |
| **Automated Analysis**   | Static analysis, linters, and vulnerability scanners    |
| **Manual Review**        | Line‑by‑line inspection of business logic               |
| **Threat Modeling**      | Identification of attack surfaces and trust assumptions |
| **Issue Classification** | Severity‑based risk assessment                          |
| **Remediation Guidance** | Clear fixes with code‑level recommendations             |
| **Re‑Audit Support**     | Verification after fixes are applied                    |

This approach ensures coverage of both **known vulnerability classes** and **protocol‑specific risks**.

## SwayScan  Open Source Static Analysis Tool

**SwayScan** is a specialized command-line static analysis security tool designed for the **Fuel blockchain's Sway language**, developed by **Safe Edges**. It performs advanced **Abstract Syntax Tree (AST) analysis** to identify vulnerabilities, code quality issues, and best practice violations in smart contracts before they reach production.

### Key Features

* Purpose-Built: Specifically designed for the Fuel ecosystem and the Sway programming language
* Static Analysis: Deep AST-based scanning with a focus on low false positives
* Vulnerability Detection: Identifies security flaws, code quality issues, and best practice violations
* Command-Line Interface: Operates as a CLI tool, commonly referred to as `forc-swayscan`
* Developed by Safe Edges: Built and maintained by the Safe Edges security research team

### Usage and Availability

* Package Registry: Available on crates.io
* Current Version: Refer to the latest published release on crates.io
* Ecosystem Focus: Designed to secure Fuel-based Web3 and DeFi smart contracts

### Link

* crates.io: [https://crates.io/crates/swayscan](https://crates.io/crates/swayscan)
